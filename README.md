## Overview
**Gamehub** is a modern platform for downloading the latest mobile and desktop video games. The website is designed to provide gamers with an easy, secure, and responsive experience. Users can sign in using Google, browse verified games with real ratings, and subscribe to a newsletter to stay updated with the latest releases.
## Live Demo
[Explore Gamehub Live](https://game-store-256c6.web.app/)

## Key Features
- Google Sign-in and Sign-up for quick and secure access  
- Verified games available for download  
- Real user ratings for every game  
- Fully responsive design for mobile, tablet, and desktop devices  
- Newsletter subscription to stay updated on new games  

## Technologies Used
- **React** – Frontend library for building UI  
- **React Router** – Client-side routing  
- **Tailwind CSS** – Modern and responsive styling  
- **Firebase** – Authentication and backend services  
- **React Icons** – Visual icons  
- **Framer Motion** – Smooth animations

## Installation & Running Locally
Follow these steps to run Gamehub on your local machine:

git clone https://github.com/alihasna32/my-nineth-assignment.git

2️⃣ Navigate to the Project Folder
cd my-nineth-assignment

3️⃣ Install All Dependencies

4️⃣ Start the Development Server
npm run dev
